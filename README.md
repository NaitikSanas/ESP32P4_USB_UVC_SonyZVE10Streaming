# Sony ZV-E10 USB video stream

This demo app uses the ESP32-P4 Function EV Board BSP, USB Host UVC driver,
and ESP32-P4 hardware JPEG decoder to show a Sony ZV-E10 USB video stream on
the ek79007 MIPI LCD Panel.

To test this app, after flashing the firmware, enable Streaming mode in Sony ZVE10 and connect it to USB Type A Host port of the ESP32-P4 Function EV Board.
